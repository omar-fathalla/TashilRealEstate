# Tashil Real Estate — Gemini AI Agent Rules

- **Default Language & Direction:** Arabic (`ar`) with RTL layout by default.
- **Multilingual Support:** All UI screens and models MUST support Arabic (RTL, Cairo font), English (LTR, Inter font), and Hindi (LTR, Noto Sans Devanagari font).
- **Localization Standards (i18n):** Reference skill `.agents/skills/trilingual-proptech-i18n/SKILL.md` and rule `.agents/rules/multilingual-ui-guidelines.md`.
- **Zero Language Mixing (النقاء اللغوي التام):** Never combine English parentheses in Arabic strings (e.g. `وكالة عقارية` not `الوكالة (Agency)`). Maintain pure language output for each locale.
- **Mandatory Tri-Language Parity:** Every new key added in `app_localizations.dart` must exist in all 3 languages (`'ar'`, `'en'`, `'hi'`).
- **Screen Reactivity:** Wrap screens/cards in `ValueListenableBuilder<Locale>(valueListenable: LocaleController.currentLocale)` for instant language updates.
- **Design System:** Material Design 3 (M3) with Slate Navy `#0F172A` and Blue `#3B82F6` color scheme. Reference handbook in `.agents/skills/material-design-3/SKILL.md` and `.agents/rules/material-design-3-components.md`.
- **Dynamic Primary-Derived Hover Engine:** All hover states, overlays, borders, and active pill backgrounds MUST be dynamically derived from the active theme's primary seed color (`M3HoverColorScheme` extension in `theme_palette_controller.dart`). Active pills and filled primary buttons on hover must darken slightly (`primaryDarkenedHover` via `Color.lerp(primary, Colors.black, 0.10)` in Light Mode, or `Colors.white, 0.12` in Dark Mode). Cards and unselected buttons on hover receive `primaryHoverStateLayer` (6-8% of primary) and `primaryHoverBorder` (42-55% of primary) with primary shadow tinting, ensuring instant, seamless adaptation across all 5 seed palettes (Warm Terracotta brown `#8F4C38`, Forest Olive green `#2E6B48`, Ocean Blue `#0061A4`, Slate Navy `#0F172A`, Emerald Teal `#006874`).
- **Button Taxonomy & Design System:** All buttons MUST adhere to the 10 official Google M3 types from `lib/core/design_system/buttons/tashil_buttons.dart` (`TashilButton`, `TashilToggleButton`, `TashilIconButton`, `TashilToggleIconButton`, `TashilSplitButton`, `TashilStandardButtonGroup`, `TashilConnectedButtonGroup`, `TashilFloatingActionButton`, `TashilExtendedFloatingActionButton`, `TashilFabMenu`). Specifically, `TashilConnectedButtonGroup` replaces deprecated baseline SegmentedButtons according to M3 Expressive guidelines with continuous `surfaceContainerHigh` stadium capsule, 24dp radius, and inner floating active pill with 220ms `easeInOutCubic` motion. When requested with "حولهالي بنفس النمط" or "طبق الـ Connected Button Group", the agent MUST immediately apply `TashilConnectedButtonGroup<T>` with `TashilConnectedButtonSegment`. **The M3 Shaded Close Button Standard (قاعدة زر الإغلاق X المضلل):** All dismiss/close buttons with 'X' (`Icons.close_rounded`, `Icons.close`, `Icons.clear_rounded`, `TashilIconButton.close`) MUST NEVER be rendered as empty, transparent, or uncolored glyphs in their resting state. They MUST always feature a circular shaded background (`surfaceContainerHighest` or `surfaceContainerHigh`) in resting state, and visibly darken upon hover (`Colors.black, 0.12` in Light Mode, or `Colors.white, 0.14` in Dark Mode) with further darkening when pressed. This guarantees high affordance, avoids bare uncolored icons, and ensures consistency across all dialogs, modals, banners, and search inputs.
- **Card Taxonomy & Design System:** All cards MUST adhere to the 3 official Google M3 types from `lib/core/design_system/cards/tashil_cards.dart` (`TashilCard.elevated`, `TashilCard.filled`, `TashilCard.outlined`). Both `TashilCard.elevated` and `TashilCard.outlined` fully implement official Google M3 Interactive States across Light and Dark themes (Elevated: Resting Level 1 1dp, Hovered Level 2 3dp with 8% state layer and -3dp lift, Focused Level 1 1dp with 10% state layer and 3dp secondary focus ring, Pressed Level 1 1dp with 10% ripple, Dragged Level 4 8dp with 16% state layer, Disabled Level 0 0dp with 38% opacity; Outlined: Resting Level 0 0dp with 1dp outlineVariant, Hovered Level 1 1dp with 8% state layer and 1dp outline, Focused Level 0 0dp with 10% state layer and 3dp secondary focus ring, Pressed Level 0 0dp with 10% ripple, Dragged Level 4 8dp with 16% state layer, Disabled Level 0 0dp with 38% opacity and muted outline). **Official Google M3 Card Measurements (Card padding and size measurements):** Shape: 12dp corner radius (11dp inner image clipping for 1dp outlined cards); Left/right padding: 16dp; Padding between cards: 8dp max (`crossAxisSpacing: 8`, `mainAxisSpacing: 8`); Label text alignment: Start-aligned (`CrossAxisAlignment.start` / `TextAlign.start`). **Official Google M3 Card Text Hierarchy (`TashilCardText`):** All card content MUST strictly follow the 3 canonical M3 text roles: (1) **Headline**: Communicates the primary subject of the card (`titleMedium`, bold); (2) **Subhead**: Smaller text elements such as an article byline or tagged location with leading icon (`bodySmall`, `onSurfaceVariant`); (3) **Supporting text**: Body content such as summary or property description (`bodySmall`, `onSurfaceVariant`, standardized strictly to 1 single line with ellipsis `...` followed by guaranteed visible clickable `linkedText` "اقرأ المزيد" opening `PropertyDetailsDialog` to ensure visual symmetry across all cards). **Official Google M3 Card Interactive Controls (`lib/core/design_system/cards/tashil_cards.dart`):** All cards support the 4 official M3 card action controls (https://m3.material.io/components/cards/guidelines#actions): (1) **Buttons**: Primary actions such as "Learn more" or "حجز معاينة" / "التفاصيل" using `TashilConnectedButtonGroup` or standard M3 buttons; (2) **Icon buttons**: Quick actions such as Save/Heart (`TashilToggleIconButton`), phone call (`Icons.phone_outlined`), or chat (`Icons.chat_bubble_outline_rounded`); (3) **Selection controls**: Chips (`TashilAssistChip` / `TashilFilterChip`), sliders, and checkboxes integrated via `selectionControl` parameter; (4) **Linked text**: Clickable link inside supporting text via `linkedText` and `onLinkedTextTap` allowing inline navigational triggers. All marketplace property cards (`PropertyCard`) MUST use `TashilCard.outlined` with crisp 1dp outline boundary to ensure total clarity and sharp edges across Light and Dark backgrounds, zero dead space and zero edge/bottom button clipping via Pinned Action Footer Architecture (`contentWidgets` in `Expanded` directly above `TashilDivider.cardAction()`, followed by the pinned action buttons footer with generous 12dp bottom and 14dp side padding guaranteeing 100% visibility without edge clipping, combined with responsive dynamic `childAspectRatio` [0.66 to 0.80] and calibrated breakpoints [<720, 720-1180, 1180-1550, >=1550]), dedicated semantic icons for every data element (price, rating, type, location, beds, baths, area, furnishing, agency), `TashilCardText` with clickable `linkedText` for details, amenity selection chips, and `TashilDivider.cardAction()` preceding the official `TashilConnectedButtonGroup` footer and quick contact icon buttons (`TashilIconButton.outlined`).
- **Carousel Taxonomy & Design System:** All property multi-image showcases MUST use the official Google M3 Carousels from `lib/core/design_system/carousel/tashil_carousels.dart` (`TashilCarousel.hero`, `TashilCarousel.multiBrowse`, `TashilCarousel.uncontained`) supporting mouse dragging, trackpad, and touch.
- **Tabs Taxonomy & Design System:** All tabbed navigation and view switches MUST use the official Google M3 Tabs from `lib/core/design_system/tabs/tashil_tabs.dart` (`TashilPrimaryTabBar`, `TashilSecondaryTabBar`, `TashilTabItem`) conforming to https://m3.material.io/components/tabs/specs with 3dp pill indicators, 48dp/64dp container heights, and responsive distribution.
- **Chips Taxonomy & Design System:** All chips MUST adhere to the official Google M3 Chip types from `lib/core/design_system/chips/tashil_chips.dart` (`TashilAssistChip`, `TashilFilterChip`, `TashilInputChip`, `TashilSuggestionChip`) conforming to https://m3.material.io/components/chips/overview with 32dp container height, 8dp squircle corner radius, 18dp leading semantic icons, and pure trilingual parity.
- **Dialogs Taxonomy & Design System:** All dialogs MUST adhere to the official Google M3 Dialog types from `lib/core/design_system/dialogs/tashil_dialogs.dart` (`TashilAlertDialog`, `TashilModalDialog`, `TashilSelectionDialog`) conforming to https://m3.material.io/components/dialogs/overview with 28dp extra-large corner radius, Level 3 tonal elevation, surfaceContainerHigh container fill, and pure trilingual parity.
- **Dividers Taxonomy & Design System:** All dividers MUST adhere to the official Google M3 Divider types from `lib/core/design_system/dividers/tashil_dividers.dart` (`TashilDivider.fullWidth`, `TashilDivider.cardAction`, `TashilDivider.inset`, `TashilDivider.middleInset`, `TashilVerticalDivider`, `TashilDivider.withLabel`) conforming to https://m3.material.io/components/divider/guidelines with 1dp thickness, `outlineVariant` color token, RTL/LTR directional awareness, and strict adherence to the **Card Dividers Rules**: (1) **Full-width dividers:** Use full-width dividers (`TashilDivider.cardAction()`) running 100% border-to-border for content that can be expanded and separating interactive card action footers from non-interactive content; (2) **Inset dividers:** Use inset dividers (`TashilDivider.middleInset()`, `TashilDivider.inset()`) which don't run the full width of a card to separate related content inside cards; and (3) **CAUTION guideline:** Use dividers sparingly to prevent visual clutter.
- **Lists Taxonomy & Design System:** All list items and reorderable lists MUST adhere to the official Google M3 List types from `lib/core/design_system/lists/tashil_lists.dart` (`TashilListTile`, `TashilReorderableList`, `TashilReorderHandle`, `M3ListsShowcaseDialog`) conforming to https://m3.material.io/components/lists/guidelines and https://m3.material.io/components/lists/specs with 56dp/72dp/88dp heights, 16dp horizontal insets, Level 3 tonal elevation floating card proxy decorator, and seamless desktop mouse drag & mobile touch hold support.
- **Loading Indicator Taxonomy & Design System:** All loading animations and indeterminate spinners MUST adhere to the official Google M3 Loading Indicator Suite from `lib/core/design_system/loading/tashil_loading.dart` (`TashilLoadingIndicator`, `TashilLoadingOverlay`, `M3LoadingShowcaseDialog`) conforming to https://m3.material.io/components/loading-indicator/overview, https://m3.material.io/components/loading-indicator/specs, and https://m3.material.io/components/loading-indicator/guidelines. It replaces indeterminate circular progress rings with an organic 4-petal morphing clover/squircle shape, smooth continuous rotation, and harmonic breathing pulse across Small (24dp), Medium (48dp), Large (72dp), and container variants.
- **Progress Indicators Taxonomy & Design System:** All progress tracking, file downloads, uploads, and data streams MUST adhere to the official Google M3 Progress Indicators Suite from `lib/core/design_system/progress/tashil_progress.dart` (`TashilLinearProgressIndicator`, `TashilCircularProgressIndicator`, `M3ProgressShowcaseDialog`) conforming to https://m3.material.io/components/progress-indicators/overview and https://m3.material.io/components/progress-indicators/specs. Supports Flat (standard) and Wavy (M3 Expressive sinusoidal wave with 40dp wavelength & 3.5dp amplitude), Determinate (0.0 to 1.0) and Indeterminate modes, signature 4dp Stop Indicator dot at the 100% position, 4dp Stop Gap, 4dp container insets, and full RTL/LTR directionality awareness.
- **Navigation Drawer Taxonomy & Design System:** All side navigation drawers and mobile sliding menus MUST adhere to the official Google M3 Navigation Drawer Suite from `lib/core/design_system/drawer/tashil_navigation_drawer.dart` (`TashilNavigationDrawer.standard`, `TashilNavigationDrawer.modal`, `TashilDrawerDestination`, `TashilDrawerSectionHeader`, `TashilDrawerProfileTile`, `M3DrawerShowcaseDialog`) conforming to https://m3.material.io/components/navigation-drawer/overview, https://m3.material.io/components/navigation-drawer/specs, and https://m3.material.io/components/navigation-drawer/guidelines with 56dp height, 28dp full stadium pill shape, 12dp directional margins, active secondaryContainer/onSecondaryContainer colors, numeric badge counters, and all 4 interactive state layers (Enabled, Hovered 8%, Focused 10%, Pressed 10%).
- **Navigation Rail & Nested Canvas Taxonomy & Design System:** All dashboard navigation rails and nested canvas layouts MUST adhere to the official Google M3 Navigation Rail Suite from `lib/core/design_system/navigation_rail/tashil_navigation_rail.dart` and `lib/core/design_system/navigation_rail/tashil_scaffold_canvas.dart` (`TashilNavigationRail`, `TashilRailDestination`, `TashilScaffoldCanvas`, `M3RailShowcaseDialog`) conforming to https://m3.material.io/components/navigation-rail/overview, https://m3.material.io/components/navigation-rail/specs, https://m3.material.io/components/navigation-rail/guidelines, and https://m3.material.io/components/navigation-rail/accessibility with 80dp compact rail mode (56x32dp active indicator pill, icon with label underneath, top-end numeric badges), animated transition to 260dp expanded mode with 250ms cubic easing, top-aligned menu toggle icon, and Nested Canvas architecture (unified surfaceContainerLowest outer canvas with zero dividing lines and inner body workspace container with 28dp top-start corner radius via `BorderRadiusDirectional.only(topStart: Radius.circular(28))` adapting to RTL/LTR).
- **Menus Taxonomy & Design System:** All dropdown menus and form selectors MUST adhere to the official Google M3 Menus Suite from `lib/core/design_system/menus/tashil_menus.dart` (`TashilDropdownMenu`, `TashilDropdownMenuItem`, `M3MenusShowcaseDialog`) conforming to https://m3.material.io/components/menus/guidelines and https://m3.material.io/components/menus/specs with 250ms top-to-bottom unfolding motion (`Curves.easeOutCubic`), 180° animated caret rotation, Level 2 elevation 12dp squircle container, 48dp item touch targets, highlighted `secondaryContainer` selected pill container, and trailing checkmarks.
- **Sliders Taxonomy & Design System:** All sliders and range selectors MUST adhere to the official Google M3 Sliders Suite from `lib/core/design_system/sliders/tashil_sliders.dart` (`TashilSlider`, `TashilSliderHandleType`, `M3SlidersShowcaseDialog`) conforming to https://m3.material.io/components/sliders/guidelines and https://m3.material.io/components/sliders/specs with 16dp expressive track height, signature 6dp Stop Gap between track segments and handle, 4x44dp vertical bar handle, animated floating value indicator balloon with `Curves.easeOutBack` spring physics, tap-to-seek, and 100% RTL/LTR directional awareness.
- **Search Taxonomy & Design System:** All search inputs and suggestion dropdowns MUST adhere to the official Google M3 Search Suite from `lib/core/design_system/search/tashil_search.dart` (`TashilSearchBar`, `M3SearchShowcaseDialog`) conforming to https://m3.material.io/components/search/overview, https://m3.material.io/components/search/guidelines, https://m3.material.io/components/search/accessibility, and https://m3.material.io/components/search/specs with 56dp container height, 28dp full stadium pill corners, subtle scale (1.008x) and Level 2 elevation transitions on focus/hover, downwards unfolding suggestions overlay with 240ms cubic easing, multi-modal tri-search integration (text typing, AI semantic vector search badge, and visual photo search button), and 100% RTL/LTR directionality awareness.
- **Switches Taxonomy & Design System:** All switch toggles and boolean controls MUST adhere to the official Google M3 Switches Suite from `lib/core/design_system/switches/tashil_switches.dart` (`TashilSwitch`, `TashilSwitchListTile`, `M3SwitchesShowcaseDialog`) conforming to https://m3.material.io/components/switch/specs and https://m3.material.io/components/switch/guidelines with 52x32dp track, full stadium rounded ends, unselected 2dp `outline` border with 16dp `outline` handle; selected `primary` fill without outline with 24dp `onPrimary` handle; animated checkmark `✓` icon inside handle (`Icons.check_rounded`); 28dp pressed state; 40dp state layer aura; 250ms cubic easing; 100% RTL/LTR directionality awareness; and tactile feedback.
- **SnackBar Taxonomy & Design System:** All notifications and snackbars MUST adhere to the official Google M3 SnackBar Suite from `lib/core/design_system/snackbars/tashil_snackbars.dart` (`TashilSnackBar.show`, `showSuccess`, `showError`, `showWarning`, `showInfo`, `M3SnackbarShowcaseDialog`) conforming to https://m3.material.io/components/snackbar/overview, https://m3.material.io/components/snackbar/specs, and https://m3.material.io/components/snackbar/guidelines with `SnackBarBehavior.floating`, Level 3 tonal elevation (6dp), 8dp squircle radius, responsive centered max-width `min(screenWidth - 32, 520)` eliminating desktop edge-to-edge stretching, dynamic seed palette derivation (`inverseSurface`, `inverseOnSurface`, `inversePrimary`), strict single action limit (`TashilSnackBarAction`), optional close affordance ('X'), and automatic previous notification dismissal (`hideCurrentSnackBar`) to prevent stacking.
- **Motion & Transitions Taxonomy & Design System:** All motion, animations, and screen transitions MUST adhere to the official Google M3 Motion Suite from `lib/core/design_system/motion/tashil_motion.dart` (`TashilMotionEasing`, `TashilMotionDuration`, `TashilMotionSpring`, `TashilTransitions`, `TashilCardFilterMotion`, `M3MotionShowcaseDialog`) conforming to https://m3.material.io/styles/motion/overview/specs, https://m3.material.io/styles/motion/overview/how-it-works, https://m3.material.io/styles/motion/easing-and-duration/tokens-specs, https://m3.material.io/styles/motion/easing-and-duration/applying-easing-and-duration, https://m3.material.io/styles/motion/transitions/transition-patterns, and https://m3.material.io/styles/motion/transitions/applying-transitions. Prohibits linear spatial motion. Features Emphasized cubic bezier curves (0.2, 0.0, 0.0, 1.0) and Standard curves, 16 duration tokens (Short 1-4, Medium 1-4, Long 1-4, Extra-Long 1-4), Faster Exit Law (~50% of entrance durations), Physics Springs (critically damped $\zeta = 1.0$, bouncy $\zeta \approx 0.76$, gentle), and the 4 Canonical Transitions: Container Transform, Shared Axis (X with Arabic RTL awareness, Y, Z), Fade Through, and Fade. **معيار موشن وانتقالات الفلترة بين الكروت (Card Filtering Motion & Transitions Protocol):** All card filtering views across properties, leases, and invoices MUST eliminate solid/instant cuts using `TashilCardFilterMotion<T>` (`lib/core/design_system/motion/tashil_card_filter_motion.dart`), combining continuous height morphing (`AnimatedSize` 300ms `emphasized`), individual card staggered cascaded entrance (`TashilStaggeredEntrance` with 35ms stagger step and 18dp `expressiveFastSpatial` slide), rapid 150ms `emphasizedAccelerate` dissolve for departing cards, and smooth empty state scaling. Whenever requested with 'إعملي نظام الفلترة', the agent MUST immediately integrate `TashilConnectedButtonGroup` with `TashilCardFilterMotion<T>`.
- **Text Fields Taxonomy & Design System:** All text and phone input fields MUST adhere to the official Google M3 Text Fields Suite from `lib/core/design_system/text_fields/tashil_text_fields.dart` (`TashilTextField.outlined`, `TashilTextField.filled`, `TashilPhoneTextField`, `M3TextFieldsShowcaseDialog`) conforming to https://m3.material.io/components/text-fields/overview and https://m3.material.io/components/text-fields/specs with 56dp standard height, 12dp squircle corners, animated floating labels with M3 cubic easing (14px interior to 12px bold header), hover/focus state layers, directional prefix/suffix icons, read-only/disabled states, helper/error text, and 100% RTL/LTR directionality awareness. `TashilPhoneTextField` incorporates an integrated country code selector (`+20` / `+971`) separated by a vertical divider, and maintains pure standalone input architecture while action triggers such as "إرسال الرمز" are placed side-by-side with matching 56dp container height and 12dp squircle corners (`TashilButton.tonal`).
- **Single-Icon Rule:** Maximum of 1 icon per button/chip. No emoji in text labels when an icon widget is present.
- **Multi-Country (EG 🇪🇬 & UAE 🇦🇪):** Multi-country scoping via `CountryController`. Strict zero country leakage (properties, currencies, cities).
- **Performance & Caching:** In-memory caching (`PropertyRepository`), composite indexes (`firestore.indexes.json`), image memory limits (`ImageUtils.cachedImage`), and localized formatting (`CurrencyFormatter`).
- **Multi-Tenant Security & Zero-Leakage:** Strictly adhere to `.agents/skills/multi-tenant-data-isolation/SKILL.md` and `.agents/rules/multi-tenant-security-and-isolation.md`. Absolute zero cross-tenant leakage. Owner properties belong to `Users/{ownerId}/properties/{propertyId}`. Public `/Properties` catalog must be sanitized (no tenant PII, no private installments). Mandatory `.where('owner_id', ...)` on shared collections. Serverless background synchronization via Cloud Functions.
