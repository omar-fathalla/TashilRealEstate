# الفحص والبناء (Verify & Build Workflow)

استخدم هذا الـ Workflow لفحص جودة الأكواد وحل مشاكل التحليل وبناء حزمة الويب:

---

## 1. الفحص والتحليل البرمجي (Static Analysis)
- تشغيل أمر تحليل فلاتر:
```bash
flutter analyze
```
- التأكد من الحصول على `No issues found!`.

---

## 2. مراجعة تكافؤ ونقاء اللغات
- التأكد من عدم وجود أي نصوص ثابتة مكتوبة يدوياً في شجرة الـ Widgets.
- التأكد من تكافؤ المفاتيح بين العربية والإنجليزية والهندية داخل `app_localizations.dart`.

---

## 3. بناء حزمة الويب (Web Build)
- تشغيل أمر البناء:
```bash
flutter build web
```
- التأكد من نجاح البناء `✓ Built build/web`.
